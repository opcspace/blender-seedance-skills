# 白模参考 + Seedance 2.5：场景与通用能力

调研日期：2026-08-09。

## 场景汇总

| 场景 | 白模负责什么 | Seedance 负责什么 | Blender Skill 应具备的能力 |
|---|---|---|---|
| 影视/动画/游戏前期预演 | 角色站位、空间关系、镜头构图、走位 | 氛围、材质、光影、动作和电影化表现 | 分镜建模、镜头轨迹、时间线、低成本迭代 |
| 建筑/室内/文旅漫游 | 房间、楼体、街区的尺度和动线 | 日夜、天气、材质、植被、人流和氛围 | 建筑 blockout、路径相机、室内外连续镜头 |
| 产品广告/电商展示 | 产品外形、比例、转台或交互动作 | 高级材质、广告灯光、环境和卖点镜头 | 参数化产品、转台、特写相机、白模/材质双输出 |
| 汽车/机器人/机械运动 | 机械结构、碰撞关系、运动轨迹 | 真实环境、速度感、尘雾和视觉特效 | 车辆/机构 blockout、父子层级、关键帧、碰撞检查 |
| 角色姿态/英雄镜头 | 低模姿态、构图和肢体方向 | 服装、面部、动作、表演和镜头气氛 | 基础人体/道具占位、骨骼或姿态参考、hero camera |
| VFX/绿幕/特效预演 | 前景/背景几何和摄像机关系 | 爆炸、烟雾、风格化背景、局部替换 | 几何代理、遮挡关系、镜头匹配、局部编辑提示词 |
| 提案/客户沟通/社媒概念验证 | 快速表达创意和空间意图 | 生成可展示的第一版视频 | 自动保存 checkpoint、批量变体、报告素材链路 |

## 提炼出的通用能力

1. **参考资产编排**：把 Blender 场景拆成主体、环境、相机、灯光、材质和运动参考；白模只保留对镜头有贡献的结构。
2. **空间与时间锁定**：明确主体相对位置、镜头焦段/运动、时间线节拍、起止姿态和必须保持不变的元素。
3. **提示词结构化**：提示词必须同时写清输入参考是什么、保持什么、发生什么动作、镜头怎么走、光影/风格怎么变、输出规格是什么。
4. **双轨交付**：同一个 Blender 场景既能导出可审阅的白模 `.blend`/图片/MP4，也能导出给即梦或火山方舟的参考素材。
5. **迭代与局部修改**：每次修改记录版本、输入参考、提示词和任务 ID；优先局部重做，不因背景或材质调整重建整个模型。
6. **一致性评估**：检查轮廓、构图、主体身份、相机方向、动作时序和遮挡关系，而不是只看画面是否“好看”。
7. **平台适配**：即梦插件走本地桥接和网页预填充；火山方舟走异步 API。两者必须共用同一份场景元数据和提示词。

## 研究依据

- Dreamina 的白模工作流页面明确把低模布局、白模、镜头方向和多模态输入用于保持构图、场景逻辑和空间关系，并列出城市 blockout、城堡、汽车追逐、室内漫游、角色姿态和提案板等例子：<https://dreamina.capcut.com/seedance/seedance-2-5-3d-blockout-to-video>
- 第三方 Seedance 2.5 功能综述将 3D 白模预可视化定位在电影、动画和场景规划，并强调镜头运动、角色/物体走位和氛围的前期验证：<https://www.goenhance.ai/zh/video-models/seedance-2-5>
- 火山方舟官方 API 文档确认视频生成采用异步任务：POST `/api/v3/contents/generations/tasks` 创建任务，返回任务 ID，再查询任务状态和视频 URL；模型参数可以是 Model ID 或推理接入点 ID：<https://api.volcengine.com/api-docs/view?action=CreateContentsGenerationsTasks&serviceCode=ark&version=2024-01-01>
- 火山方舟官方任务列表文档确认可以按 `filter.task_ids` 查询任务，并使用 `queued`、`running`、`succeeded`、`failed` 等状态：<https://api.volcengine.com/api-docs/view?action=ListContentsGenerationsTasks&serviceCode=ark&version=2024-01-01>

## API 现实边界

截至调研日期，公开火山方舟 API 文档示例仍以 Seedance 1.x 或控制台可见模型为主，公开检索未能确认一个稳定、统一的 Seedance 2.5 API Model ID。Skill 不猜测模型名；用户需要在火山方舟控制台开通视频能力，并把实际 Model ID 或推理接入点写入 `VOLCENGINE_SEEDANCE_MODEL`。如果 2.5 只在即梦/Dreamina 网页可用，就走 Jimeng uploader 分支。
