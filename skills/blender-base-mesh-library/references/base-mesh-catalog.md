# BaseMesh catalog and retrieval keywords

Use Chinese and English terms together when searching local files, online libraries or a future asset index. The keyword list is intentionally broad so a natural-language request can map to a stable category.

## 1. Character / 角色人物

- 写实人体素体 / realistic human base mesh / male female child elder mannequin
- 二次元素体 / stylized character base / anime body / chibi / Q-version / toon
- 头部 / head base / face blockout / facial topology
- 手脚 / hand base / foot base / palm / finger blockout
- 发型服饰盔甲基底 / hair base / clothing base / armor blockout
- 绑定素体 / rig-ready mannequin / humanoid base / armature-ready

## 2. Creature / 生物

- 哺乳动物 / mammal base / quadruped
- 鸟类 / bird base / wing base / featherless bird
- 鱼类 / fish base / aquatic creature
- 爬行类 / reptile base / lizard / snake
- 龙 / dragon base / dragon head / winged creature
- 兽人魔物人鱼精灵 / beastfolk / monster / merfolk / elf base
- 兽爪翅膀角 / claw / wing / horn / talon

## 3. Props and still life / 道具静物

- 家具餐具工具 / furniture / table / chair / utensil / tool
- 刀剑枪械盾牌 / sword / knife / firearm / shield / weapon blockout
- 小摆件饰品乐器 / ornament / jewelry / prop / instrument
- 无贴图外形 / untextured prop / white prop / graybox asset

## 4. Architecture / 建筑

- 柱子门窗雕花台阶 / column / door / window / trim / stair / architectural kit
- 古风房屋现代楼房科幻建筑 / traditional house / modern building / sci-fi building
- 城市模块墙体框架 / modular city / wall kit / facade / structural frame
- 室内白模 / interior blockout / room shell / walkthrough layout

## 5. Hard surface and machines / 硬表面机械

- 车飞船机甲 / vehicle / car blockout / spacecraft / mech
- 机器人壳体设备外壳 / robot shell / equipment housing / industrial casing
- 工业零件 / industrial part / mechanical component / panel / hinge
- 无划痕无材质壳体 / clean hard surface / untextured mechanical shell

## 6. Environment and terrain / 环境地形

- 山体岩石石块 / mountain blockout / cliff / rock / boulder
- 树木植被基底 / tree base / trunk / branch / vegetation proxy
- 石头碎石地表模块 / stone kit / gravel / terrain tile / ground module

## 7. Abstract forms / 抽象基础形体

- 球立方体圆环圆柱 / sphere / cube / torus / cylinder / primitive
- 艺术雕塑异形曲面 / sculpture base / organic blob / irregular surface
- 二次雕刻 / sculpt base / remesh base / clay blockout

## Search output format

When reporting a search or selection, return: `category`, `asset family`, `keywords used`, `source/path`, `rig_ready`, `material state`, `scale`, and `next modification step`.
